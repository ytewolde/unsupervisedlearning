# Pattern Lab
**Discover patterns. Explain your thinking.**

Pattern Lab is a free, browser-based interactive learning tool designed to help students explore and understand **unsupervised machine learning**.

Students can build, train, visualize, and evaluate K-means clustering models without writing code. The application makes machine learning concepts more accessible through experimentation, data exploration, and visual feedback.

**[Launch Pattern Lab](https://ytewolde.github.io/unsupervisedlearning/)**

## What Can You Do with Pattern Lab?

- **Explore datasets:** Use built-in sample datasets or upload your own numerical CSV data.
- **Select features:** Investigate how different data features influence clustering.
- **Train models:** Experiment with K-means clustering and observe how centroids and cluster assignments change.
- **Visualize patterns:** Explore data through interactive 2D and 3D plots, including PCA and t-SNE visualizations.
- **Compare models:** Change the number of clusters (K) or selected features to investigate how results differ.
- **Interpret results:** Examine individual data points, cluster characteristics, and model limitations.
- **Document learning:** Create model cards, save comparisons, and export evidence from investigations.

## Getting Started

1. Open [Pattern Lab](https://ytewolde.github.io/unsupervisedlearning/).
2. Choose a sample dataset or upload your own CSV file.
3. Select the numerical features you want to investigate.
4. Choose the number of clusters and train your model.
5. Explore the results and examine patterns within the data.
6. Change a setting, retrain, and compare your results.
7. Document your findings and explain what your model reveals.

No programming experience, account, or software installation is required.

## Designed for Learning

Pattern Lab was developed primarily for high school students studying artificial intelligence and machine learning.

The application supports students in exploring questions such as:

- How can a machine learning model discover patterns without labeled examples?
- How do the features we select influence clustering results?
- What happens when we change the number of clusters?
- How can we interpret and compare different clustering models?
- What are the limitations of the patterns our models identify?

**An important distinction:** K-means discovers mathematical groupings based on the selected features. These clusters are not automatically meaningful categories, and there is not necessarily one correct grouping.

Students are encouraged to support their interpretations with evidence rather than simply accepting the results of a model.

## For Educators

Pattern Lab can support demonstrations, guided investigations, independent learning activities, and formative or summative assessments.

Students can document their decisions, compare different models, and evaluate the strengths and limitations of unsupervised learning.

A [Teacher Guide](https://ytewolde.github.io/unsupervisedlearning/guide.html) provides classroom suggestions, technical explanations, and additional information about the application.

## Data and Privacy

Pattern Lab runs locally within the user's browser and does not require student accounts or a cloud-based machine learning service.

Students can download their projects for later use. Browser-based autosaving should not be treated as permanent storage or an assignment submission system.

Sample datasets and their sources are documented within the project.

## About This Project

Pattern Lab is an educational project developed to make unsupervised machine learning more approachable, visual, and interactive.

It is intended to complement classroom instruction by helping students move beyond definitions and engage directly with the process of building and evaluating machine learning models.
